# DESIGN.md — ScienceX · AI 科研工作台 · 项目路演答辩

## 1. 画布与全局母版

- 画布：1280 × 720（16:9）。
- 母版三区（内容页统一）：
  - **A 标题块**：y 0–120（章节标签胶囊 12px + 主标 30px bold + 细分隔线），左对齐，左侧留 4px 墨绿竖线作锚。
  - **B 内容区**：y 120–660（可用 540px 高）。
  - **C 页脚条**：y 660–720，左侧「ScienceX · AI 科研工作台」12px 灰，右侧页码 `NN / 22` 12px 灰。
- 页面 padding：左右 60，上下 20（安全区，不用绝对定位绕过）。
- 封面 / 目录 / 章节扉页 / 结束页允许自定义版式（无 A/C 或弱化）。

## 4. 密度与版式原则

- 内容页 C 区累计高 ≥ 480px，宽 = 1160px；卡片填充率 ≥ 80%，尾部数据/标签用 `marginTop:'auto'` 锚底。
- 每页一个主结论，标题写观点；相邻页版式必须不同；连续 ≥2 页等宽卡片横排即返工。
- 每页 ≥1 个视觉锚点（巨数字 / 大色块 / 大图 / 主表）。
- 常规页留白 ≤ 35%；章节扉页/封面/结束页为「留白型」例外。

## 5. 配图系统

- **L1 主视觉**：`assets/hero.png`（ScienceX 吉祥物双人图，2048²）用于封面 P00 右侧 + 结束页 P21；统一为 3D 卡通风格，全篇仅封面/结束页使用，保持视觉呼应。
- **L3 角标**：`assets/logo.png`（蓝色 X 徽标，512²）仅用于封面与结束页品牌落款。
- 其余页面的流程图 / 时间轴 / 架构图 / 评分条 / 阶梯图 / 对比表 / 巨数字，一律用 **Box / Text / Table / Chart / SVG** 结构化绘制，不用 AI 生图（避免风格混杂、保持学术严谨）。

## 6. 渐变与半透明

- 章节扉页：深墨绿 `#0E4A37` 满版 + 超大数字琥珀色 12% 透明叠底。
- 结论条 / 金句条：墨绿浅底 `#E3F1EA` 或琥珀浅底 `#FAF0E1`，左侧 4px 品牌色竖线。
- 卡片：白底 `#FFFFFF` + 浅描边 `#E6E2D6` + 轻投影 `0 2px 12px rgba(0,0,0,0.06)`，禁渐变作卡背景。
- 渐层仅允许在封面/章节扉页的光晕装饰（低透明度，≤0.15）。

# 2026-10-03 工作日志

## 文献阅读模块「文献导入」全链路实现

**目标**：ScienceX 文献阅读模块支持 PDF / Word(.docx) / Markdown / CAJ 四格式导入 → 结构化解析 → 沉浸式阅读，含划词高亮批注与划词翻译。

### 后端
- 新增 `backend/src/lib/parser.js`（约 760 行）：零第三方 Node 依赖的多格式解析引擎。
  - PDF：调用系统 Python 的 **PyMuPDF**（`import pymupdf`，兼容旧 `fitz`），逐页抽取文本层 + 检测首页标题/作者并从正文剥离。
  - DOCX：手写 ZIP 读取器（`readZipEntries` + `zlib.inflateRawSync`）解析 `word/document.xml`，并从 `docProps/core.xml` 取标题/作者。
  - Markdown：解析 `#` 标题层级、`作者/摘要` 元信息、剔除代码块与表格行。
  - CAJ：识别 `CAJ-C`/`TEBX` 签名；检测内嵌 `%PDF` 头；兜底用 UTF-16LE/GBK 可打印字符密度扫描提取可阅读片段。
  - 统一产出 `{title, authors, abstract, sections[], figures[], text, pages, meta}`；任何失败都降级为说明性结构化正文，绝不抛错中断导入。
  - 关键坑：Python 候选解释器逐个尝试时必须用 `accept` 回调校验 `ok:true`，否则缺少 PyMuPDF 的解释器会返回 `ok:false` 被误当作成功结果。
- `backend/src/routes/documents.js`：重写 `POST /documents/upload`，接 base64（`file_content`）或文本（`content`），按扩展名分派解析，50MB 校验，返回 `parse_meta`（degraded/engine/pageCount）。
- `backend/src/server.js`：上传路由单独放宽 `express.json` 限制至 72MB（50MB 文件的 base64 体积）。

### 前端
- `frontend/src/components/DocViewer.tsx`：扩展 `DocKind` 增加 `markdown`/`caj`；新增 CAJ 降级视图（说明 + 转 PDF 引导 + 可阅读片段展开）、Markdown 结构化渲染、Office 引擎自动兜底、`parseMeta` 降级标签。
- `frontend/src/pages/reader/ImmersiveReader.tsx`：新增划词翻译内联卡片（`InlineTransCard`），自动判断中↔英方向、加载/错误/重试态、术语表展示、译文持久化到 localStorage。
  - **关键修复**：划词工具栏闪烁问题。原 `selectingRef` 布尔量 + `setTimeout(0)` 会在 React 提交前释放，导致 document 级 capture `mousedown` 立刻关闭工具栏。改为**时间戳守卫**（`performance.now() + 350`）并在 `onDown` 中排除 `[data-selection-popup]`。
- `frontend/src/pages/Reader.tsx`：新增「阅读 / 原文档」双模式切换按钮、`IMPORT_ACCEPT` 格式白名单、`acceptFile` 格式/50MB 校验、`readAsBase64`、拖拽（含 `dragOver` 高亮）、`translateText` 接口、导入后自动进入沉浸式阅读、降级提示 toast。
